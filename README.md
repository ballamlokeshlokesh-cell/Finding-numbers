# Finding Numbers

A small browser-based number sequence game built with HTML, CSS, and JavaScript.

## Overview

The player must find hidden numbers in ascending order before the timer reaches zero. The game includes multiple difficulty levels, timer modes, and endless level progression up to level 100.

## How to Run

1. Open the repository in your browser.
2. Open `index.html` directly in a browser, or serve the project with a local static server.
3. Start playing.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Files

- `index.html` — the game UI, styling, and game logic.

## Features

- Easy, medium, and hard modes
- Standard, no-timer, and custom timer options
- Level-based progression
- Responsive layout for desktop and mobile screens
